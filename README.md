# mbt-app-pilot

**Awareness Loop — MVP**

A gentle wake-up system for attention. The loop:
**Prompt → State → Awareness Cue → Return to life.**

Static frontend + Vercel serverless functions for iOS Web Push reminders.

## Layout

- `index.html`, `styles.css`, `app.js` — three-screen frontend
- `manifest.webmanifest` — PWA manifest (`display: standalone` is required for iOS push)
- `sw.js` — service worker; handles push events and notification clicks
- `icon-*.png`, `apple-touch-icon.png` — generated by `scripts/generate-icons.mjs`
- `api/vapid.js` — exposes the public VAPID key to the frontend
- `api/subscribe.js` — `POST` to register, `DELETE` to remove
- `api/cron/ping.js` — auth'd endpoint that sends one bell to every subscription
- `api/_upstash.js` — small Upstash REST helper
- `vercel.json` — cron schedule + service-worker headers

## One-time setup

### 1. Generate VAPID keys

```sh
npm install
npm run vapid
```

Outputs `VAPID_PUBLIC_KEY=...` and `VAPID_PRIVATE_KEY=...`. Save them.

### 2. Provision Upstash Redis

Free tier is fine. Either:

- Vercel dashboard → Storage → Marketplace → **Upstash for Redis**, attach to project. Vercel will auto-inject `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.
- Or sign up at [upstash.com](https://upstash.com), create a Redis database, copy the REST URL and token into Vercel project env vars.

### 3. Set Vercel environment variables

Project Settings → Environment Variables:

| Name | Value |
| --- | --- |
| `VAPID_PUBLIC_KEY` | from step 1 |
| `VAPID_PRIVATE_KEY` | from step 1 |
| `VAPID_SUBJECT` | `mailto:you@example.com` (must be `mailto:` or `https://`) |
| `CRON_SECRET` | a random string, e.g. `openssl rand -hex 32` |
| `UPSTASH_REDIS_REST_URL` | from step 2 |
| `UPSTASH_REDIS_REST_TOKEN` | from step 2 |

### 4. Deploy

Push to the branch Vercel watches. Vercel installs deps and deploys.

### 5. On the iPhone

1. Open the deployed URL in Safari.
2. **Re-add to Home Screen** (Share → Add to Home Screen). The previous icon was added before the manifest existed; iOS won't upgrade it in place.
3. Open the app from the home-screen icon (it must launch standalone — no Safari chrome).
4. Tap **Turn on gentle reminders**. Approve the permission prompt.
5. Reminders should now fire on schedule, even with the phone locked.

## Cron

Default schedule in `vercel.json`: `0 14,17,20,23 * * *` UTC (= roughly 4× per day during waking hours in most US time zones). Adjust to taste.

**Vercel Hobby tier is limited to daily-only crons.** If you're on Hobby and want multi-time pings, either:

- Upgrade to Pro, or
- Use a free external pinger (e.g. [cron-job.org](https://cron-job.org)) hitting `https://<your-domain>/api/cron/ping` with header `Authorization: Bearer <CRON_SECRET>`.

## Data

Locally per browser, in `localStorage` under `awareness_checkins_v1`:

```json
{
  "timestamp": "2026-05-06T12:00:00.000Z",
  "state": "wandering",
  "stateLabel": "Wandering",
  "intervention": "Take one conscious breath.",
  "feedback": "yes"
}
```

Push subscriptions live in Upstash under the set key `awareness:subs`.

## Notes & known iOS quirks

- iOS web push requires the PWA to be installed to the home screen and launched standalone.
- Every push **must** show a visible notification. `sw.js` does this inside `event.waitUntil()` — don't refactor that out, or iOS will revoke the subscription after a few pushes.
- No notification sound is available for web push on iOS yet; vibration only.
- iOS Focus / Do Not Disturb modes hide reminders as you'd expect.
- If you don't open the PWA for a long stretch, iOS may expire the subscription. Opening the app re-subscribes silently.
